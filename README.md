# Geeks-for-Geeks Daily Problem Solving

Welcome to my Geeks-for-Geeks daily problem-solving repository!  
In this repository, I solve one problem from **GeeksforGeeks** every day, and upload the Java code solution along with a screenshot of the problem.

### Problem Solving Approach:
- Every day, I pick a problem from **GeeksforGeeks** and solve it in Java.
- I upload the solution as a `.java` file and a screenshot of the problem statement for that day.
- The problems vary in difficulty, from beginner to advanced levels.

### Repository Structure:
- **Day1**, **Day2**, **Day3**, ... : Each folder represents the problem for a specific day. 
  - Inside each folder:
    - **Java Code**: A `.java` file containing the solution code for the problem.
    - **Screenshot**: A screenshot of the GeeksforGeeks problem statement for that day.

### Example Folder Structure:
Geeks-for-Geeks │ ├── Day1 │ ├── Solution.java │ └── problem.png │ ├── Day2 │ ├── Solution.java │ └── problem.png │ └── Day3 ├── Solution.java └── problem.png

### How to Navigate:
- Each folder is named by the day (e.g., `Day1`, `Day2`, etc.).
- Inside each folder, you will find:
  - `Solution.java`: The Java code that solves the problem.
  - `problem.png`: A screenshot of the problem statement from GeeksforGeeks.

### Example:
For **Day 1**, the folder `Day1` would contain:
- `Solution.java`: Java code that solves the problem.
- `problem.png`: A screenshot showing the GeeksforGeeks problem statement.

### Motivation:
This repository is my way of keeping track of my progress as I practice solving coding problems daily. It helps me improve my coding skills by providing consistent practice.
